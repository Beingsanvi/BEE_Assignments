# 🌐 Personal Portfolio

A modern and responsive personal portfolio website built using **HTML**, **CSS**, and **JavaScript**.

## 📌 Features

- Responsive design
- Dark theme
- Smooth scrolling
- Animated navigation bar
- Typing animation
- Skills section
- Projects section
- Education section
- Contact section

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
portfolio/
│── index.html
│── style.css
│── script.js
```

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/Beingsanvi/BEE_Assignments.git
```

2. Open the `portfolio` folder.

3. Open `index.html` in your browser.
